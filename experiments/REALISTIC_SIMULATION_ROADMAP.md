# 数字孪生仿真逼近真实环境路线图

当前目标：

> 基于真实天气 + 文献参数 + 可解释机理，构建高可信仿真环境。

## 优先级

先做：

- [ ] 1. 逐日天气驱动
- [ ] 2. 夜间 ETc 非零

后做：

- [ ] 3. 土壤参数校准
- [ ] 4. 灌溉水量口径统一
- [ ] 5. EC 模型修正
- [ ] 6. 加入真实扰动

## 1. 逐日天气驱动

现状：

- `weather_client.py` 可以查询 ET0 和降雨。
- 当前短期事件响应脚本已支持 `--weather`。
- 但仿真主要还是使用单日 ET0 / rain 代表整个仿真过程。

要做：

- 5 天仿真使用 5 天逐日天气。
- 90 天季节仿真使用逐日天气、缓存天气或文献多年平均天气。
- 每个仿真日更新一次 `ET0` 和 `rain_mm_day`。

目标：

- Day 1 使用 `ET0[0]`、`rain[0]`
- Day 2 使用 `ET0[1]`、`rain[1]`
- Day 3 使用 `ET0[2]`、`rain[2]`

## 2. 夜间 ETc 非零

现状：

- 当前 ETc 有明显日周期。
- 夜间 ETc 可能接近或等于 0。

要做：

- 在 `config/simulation.yaml` 的 `day_night` 中增加：

```yaml
nighttime_et_fraction: 0.08
```

含义：

- 夜间保留全天 ET 的 8% 左右。
- 白天承担剩余蒸散量。

目标：

- 夜间 ETc 很低，但不为 0。
- ETc 曲线更接近真实环境。

## 3. 土壤参数校准

要整理沙壤土文献参数：

- `theta_sat`
- `theta_fc`
- `theta_wp`
- `K_sat`
- `root_depth`

没有实测数据时：

- 使用文献区间。
- 做敏感性分析。

## 4. 灌溉水量口径统一

现状：

- T1/T2 计划总灌溉量为 180 mm。
- 仿真实际灌入量可能略有偏差。

要做：

- 灌溉制度图展示计划水量。
- 水分模型输入严格按计划水量换算。

目标：

- T1/T2 对比更严谨。

## 5. EC 模型修正

现状：

- 当前 EC 曲线明显低于阶段目标 EC。

要检查：

- 肥液浓度 `ec_conc`
- 施肥流量 `q_f`
- 混肥罐模型
- 土壤 EC 稀释 / 累积模型
- 目标 EC 是否过高

目标：

- EC 响应能接近作物阶段目标。
- SAC 后续训练有明确控制意义。

## 6. 加入真实扰动

可加入：

- 传感器噪声
- 降雨随机性
- ET0 波动
- 土壤参数扰动
- 管道延迟扰动
- 滴头流量不均匀

目标：

- 避免 SAC 在过于理想的环境中训练。

## 7. 参数敏感性分析

建议扰动范围：

- `ET0 ±20%`
- `rain ±20%`
- `theta_fc ±10%`
- `K_sat ±20%`
- `ec_conc ±20%`

目标：

- 检查结果是否稳定。
- 提高仿真可信度。

## 8. 试验台 / 田间校准

没有机器时：

- 先做到文献参数 + 真实天气 + 可解释机理。

有试验台后：

- 用实测 EC / pH / 流量校准混肥罐和管道。

有田间数据后：

- 用土壤水分、EC、pH、产量数据校准土壤和作物模型。
