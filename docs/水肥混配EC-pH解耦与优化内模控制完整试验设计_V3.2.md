> 版本日期：2026-07-27

> 第一篇小论文定位：水肥混配过程控制与试验台验证  
> 当前安全状态：`Decoupler_Enable = FALSE`

## 0. 最终方案结论

第一篇小论文不再以田间数字孪生和季节灌溉优化为主线，而是先解决一个更集中、可验证的问题：

**在水肥混配试验台上，约束解耦与离线优化的内模控制能否提高出口 EC 跟踪精度，并使 pH 稳定保持在合理区间内。**

完整证据链为：

```text
试验台搭建与计量标定
→ 低/中/高工作点 EC-pH 耦合对象辨识
→ 受约束的局部解耦设计
→ 内模 PI/PID 与 Smith 延迟补偿
→ PSO 在上位机离线整定控制参数
→ 仿真消融与鲁棒性比较
→ 参数冻结
→ 物理试验台独立闭环验证
→ 形成小论文
```

这篇论文回答的是“水肥如何准确、安全地配出来”，不回答“田间每个生育阶段应该灌多少、施多少”。田间数字孪生和季节水肥优化留作第二篇论文。

首选题目：

> **Accurate EC tracking and bounded pH regulation in a fertigation mixing system: simulation and test-bench validation**

### 0.2 论文允许和不允许的结论

允许：

- 控制方法在水肥混配物理试验台上完成闭环验证。
- 所提方法提高了出口 EC 跟踪精度。

## 1. 研究目标与科学假设

### 1.1 总体目标

建立一套包含主水泵、NPK 混合母液泵、酸泵、混合单元、EC/pH/流量/压力传感器（N/P/K 预先混合为统一母液，由单一泵注入）和 S7-1214C 控制器的物理试验台。在三个代表性工作点上辨识 EC-pH 双输入双输出动态模型，设计受约束的局部解耦与内模控制器，使用 PSO 离线整定少量可解释参数，并通过仿真和物理试验验证 EC 精度、pH 区间、安全性和鲁棒性。

### 1.2 研究问题

1. 总营养液投加量 `q_f` 和酸液投加量 `q_a` 对出口 EC、pH 的局部增益、延迟和时间常数能否稳定辨识？
2. 解耦能否降低非目标回路响应，同时不恶化 EC 主回路、不增加泵饱和和低 pH 风险？
3. 内模控制相对固定 PI 是否能够提高大滞后混配过程的动态性能？
4. PSO 离线整定是否能够在多工况约束下进一步改善 EC 精度和 pH 带内率？
5. 仿真中的改善能否在未参与整定的真实试验台批次和扰动条件下复现？

### 1.3 预注册假设

| 假设 | 内容 | 主要判据 |
|---|---|---|
| H1 | 三个工作点的局部模型可重复辨识 | 关键增益符号正确，增益 CV ≤20%，条件数 ≤10，每点至少 3 次 |
| H2 | 约束解耦降低 EC-pH 交叉耦合 | 平均交叉响应降低 ≥20%，主回路 IAE 退化 ≤10% |
| H3 | 优化型内模控制提高 EC 跟踪精度 | 中工作点稳态 EC MAE ≤0.03 dS/m；全部工况 EC MAE ≤0.05 dS/m |
| H4 | pH 保持在农业配液合理区间 | pH 5.8-6.5 带内时间 ≥95%，最低 pH ≥5.5 |
| H5 | 改善能够从仿真迁移到试验台 | 试验台相对基线的效应方向与仿真一致，且不增加安全事件和持续饱和 |

## 2. 试验台系统设计

### 2.1 最低硬件组成

| 子系统 | 最低组成 | 设计要求 |
|---|---|---|
| 主水路 | 储水箱、主水泵、调速或变频、总流量计、压力传感器 | 主水流可稳定设定，并可注入 ±10% 扰动 |
| NPK 混合母液路 | N/P/K 母液箱（按配方预混）、计量泵、止回阀、隔离阀、冲洗口 | 可独立标定和停泵 |
| 酸路 | 低浓度酸液箱、耐腐蚀计量泵、止回与冲洗 | 只能主动降低 pH，必须有低 pH 禁加酸 |
| 混合单元 | 混合罐或静态混合器、循环/旁路、出口取样口 | 有效体积、搅拌和停留时间可测 |
| 在线测量 | EC、pH、温度、总流量、压力 | EC 不确定度需要支持 0.03-0.05 dS/m 的精度判别 |
| 控制 | S7-1214C、KTP900 Basic、上位机 | PLC 拥有最终泵命令和安全权限 |
| 安全 | 硬急停、调试钥匙、接触器或驱动 STO、泄漏和溢流措施 | 不能用 HMI 软件急停替代物理安全回路 |

### 2.2 为什么仍然采用 2×2 控制对象

真实执行层只有 NPK 混合母液泵和酸泵两路计量泵。N/P/K 三种母液按固定配方预先混合为统一母液，由单一泵注入主管路。第一篇论文将 NPK 混合母液流量和酸液流量作为两个控制输入，建立 2×2 EC-pH 模型。

定义：

- `q_f`：NPK 混合母液泵流量命令（N/P/K 配比由预混母液配方决定，不在控制回路中分配）。
- `q_a`：酸液泵流量命令。
- `q_w`：主水流，作为固定工作点或外部扰动。

因此快速混配对象为：

```text
输入 u = [q_f, q_a]^T
输出 y = [EC, pH]^T
扰动 d = [q_w, 母液浓度, 温度, 管路延迟]^T
```

局部稳态增益矩阵为：

```text
             [ G_EC_F   G_EC_A ]
G0       =   [                   ]
             [ G_pH_F   G_pH_A ]
```

这样在真实硬件层面仅需两个计量泵（NPK 混合母液泵和酸泵），避免了第一篇论文出现难以辨识、样本量过大的多输入控制问题。

### 2.3 pH 的正确控制定义

当前执行机构只有酸泵，能够主动降低 pH，不能对称地主动提高 pH。因此：

- EC 是精确跟踪目标。
- pH 是区间约束目标。
- 推荐正常区间：5.8-6.5。
- 名义目标：6.2。
- 硬安全下限：5.5。
- 当 `pH ≤ 5.8` 时，酸泵停止。
- 当 `pH < 5.5` 时，进入低 pH 故障，需要人工确认后恢复。

论文不能把酸液单向系统描述为“双向高精度 pH 跟踪”。

## 3. 对象辨识方案

### 3.1 局部动态模型

在每个工作点附近使用增量模型：

```text
Δy(s) = G(s) Δu(s)
```

每个通道首先拟合带纯滞后的一阶模型：

```text
G_ij(s) = K_ij × exp(-L_ij s) / (T_ij s + 1)
```

其中：

- `K_ij`：通道稳态增益。
- `L_ij`：纯滞后。
- `T_ij`：时间常数。

只有当独立验证残差显示明显二阶结构时，才允许升级模型阶次。不能为了提高拟合度无限增加模型复杂度。

### 3.2 三个工作点

| 工作点 | 主水流 | EC 目标 | pH 初始条件 | 用途 |
|---|---:|---|---|---|
| Low | 额定流量约 60% | 阶段低 EC | 6.4-6.7 | 低负荷泛化 |
| Medium | 额定流量约 80% | 常用 EC | 6.4-6.7 | 完整辨识、消融和整定 |
| High | 额定流量约 100% | 阶段高 EC | 6.4-6.7 | 高负荷泛化 |

实际 EC 数值应在母液和传感器标定后确定，并在正式辨识前冻结。

### 3.3 阶跃试验

每个工作点执行：

1. 稳定主水流，运行 20-30 min 基线。
2. 执行 `q_f` 正阶跃。
3. 恢复到基线。
4. 执行 `q_f` 负阶跃。
5. 恢复到基线。
6. 执行 `q_a` 正阶跃。
7. 通过清水置换恢复，不要求酸泵产生负流量。
8. 每个阶跃至少独立重复 3 次。

阶跃顺序应随机化或平衡化，避免温度、母液老化和传感器漂移与输入通道混杂。

### 3.4 采样与记录

建议 PLC 记录周期为 1 s 或更快，至少保存：

- 时间戳和 `run_id`。
- `q_w`、压力和温度。
- `q_f_cmd`、`q_a_cmd` 及各泵实际流量。
- EC 设定值和实际值。
- pH 上下限、名义目标和实际值。
- 泵限幅、抗饱和和负命令投影状态。
- 解耦有效位、权重、G 矩阵版本。
- 水流、传感器、驱动、急停和通信状态。

### 3.5 辨识数据分组

- 重复 1、2：用于模型参数辨识。
- 重复 3：用于独立模型验证。
- 如果增加新的母液批次，优先把完整新批次作为外部验证。
- 不允许把同一次阶跃的相邻采样点随机拆分为训练和验证数据。

### 3.6 模型通过条件

| 条件 | 建议门槛 |
|---|---:|
| 关键增益重复 CV | ≤20% |
| 增益方向 | 与物理机理一致 |
| 稳态矩阵条件数 | ≤10 |
| 行列式绝对值 | 高于预先登记的最小值 |
| 验证集拟合 | 无持续偏差和明显结构性残差 |
| 泵状态 | 无持续上下限饱和 |
| 安全事件 | 0 |

## 4. 解耦控制设计

### 4.1 解耦原则

采用局部静态或部分解耦，不追求数学上的完全逆解。

解耦权重：

```text
β ∈ [0, 0.5]
β = 0 表示关闭解耦
```

解耦仅在以下条件全部成立时允许参与计算：

```text
Decoupler_Enable = TRUE
AND Decoupler_Valid = TRUE
AND abs(det(G0)) ≥ determinant_min
AND G_EC_F > 0
AND G_pH_A < 0
AND Water_Flow_OK = TRUE
AND 所有执行许可成立
```

### 4.2 为什么使用部分解耦

完全求逆可能造成：

- 噪声放大。
- 负泵命令。
- 酸泵或营养液泵饱和。
- 小模型误差引起严重过补偿。
- pH 低于安全范围。

因此使用受约束的部分解耦，并在最终输出前执行：

- 非负投影。
- 泵流量上下限。
- 变化率限制。
- 无水禁加药。
- pH 低限禁加酸。
- 抗积分饱和。

### 4.3 解耦通过标准

解耦必须同时满足：

| 评价项 | 通过标准 |
|---|---:|
| 平均交叉响应降低 | ≥20% |
| 单次重复 | 不出现不可接受的交叉响应恶化 |
| EC/pH 主回路 IAE | 相对无解耦退化 ≤10% |
| EC 精度 | 达到第 8 节门槛 |
| pH 带内率 | ≥95% |
| 最低 pH | ≥5.5 |
| 泵饱和 | 不高于无解耦基线 |
| 安全事件 | 不增加 |
| 批准文件 | `passed=true`、`selected_weight` 非空、`approval_written=true` |

### 4.4 当前解耦状态

最新 HIL A/B 报告显示：

- `β=0.1` 平均交叉耦合降低约 40%。
- `β=0.25` 平均交叉耦合降低约 50%。
- EC MAE 为 0.03503 dS/m。
- HIL EC MAE 门槛为 0.03 dS/m。
- `passed=false`。
- `selected_weight=null`。
- `approval_written=false`。

因此当前必须保持：

```text
Decoupler_Enable = FALSE
```

新试验方案不能改变当前未通过的事实。必须用新的模型、仿真和物理试验结果重新判定。

## 5. 内模控制与 PSO 离线整定

### 5.1 控制器实现口径

当前工程已有 `IMC-PI/Smith` 路线，适合大滞后、噪声较强的混配过程。

建议学术和工程表述如下：

- 总体方法称为“优化型内模控制”或“离线优化的内模-PID执行层”。
- 如果实际程序中 `Kd=0`，方法部分必须明确写 `IMC-PI/Smith`。
- 只有 D 项真实实现、在噪声下通过验证且确实改善性能，才可以写 `IMC-PID`。
- 不为算法名称强行保留微分项。

### 5.2 推荐对照控制器

采用“解耦开关 × 整定方式”的 2×3 因子设计：

| 控制器 | 解耦 | 整定方式 | 作用 |
|---|---|---|---|
| C0 | OFF | 现有固定 PI | 基础基线 |
| C1 | ON | 固定 PI | 分离解耦贡献 |
| C2 | OFF | 解析 IMC-PI/PID | 分离内模整定贡献 |
| C3 | ON | 解析 IMC-PI/PID | 解耦 + 内模基线 |
| C4 | OFF | PSO 离线优化 IMC 参数 | 分离 PSO 整定贡献 |
| C5 | ON | PSO 离线优化 IMC 参数和 β | 拟议完整方法 |

这个矩阵比只比较“普通 PID”和“PSO-IMC-PID”更有说服力，因为能够回答性能到底来自解耦、内模结构还是离线整定。

### 5.3 PSO 的运行位置

```text
试验台辨识模型
→ Python 上位机离线 PSO
→ 输出锁定的 λ_EC、λ_pH、β
→ 由 IMC 公式转换为 PI/PID 参数
→ 参数审查和哈希锁定
→ 下载/写入 PLC
→ PLC 实时运行固定参数
```

PSO 不应：

- 在 S7-1214C 扫描周期中运行。
- 在线反复试错。
- 直接输出泵流量。
- 根据最终试验台结果继续调参。

### 5.4 PSO 决策变量

推荐基础向量：

```text
x = [λ_EC, λ_pH, β]
```

建议边界：

| 变量 | 建议边界 | 含义 |
|---|---|---|
| `λ_EC` | `max(L_EC, 30 s)` 至 `600 s` | EC 内模滤波/控制速度 |
| `λ_pH` | `max(L_pH, 30 s)` 至 `900 s` | pH 内模滤波/控制速度 |
| `β` | 0 至 0.5 | 部分解耦权重 |
| `N`（可选） | 5 至 20 | 仅在启用 D 项时使用的微分滤波比 |

不建议一开始直接搜索两个回路的 6 个任意 PID 增益。搜索少量有物理含义的 IMC 参数更容易复现，也更不容易过拟合。

### 5.5 PSO 设置

| 参数 | 预注册值 |
|---|---:|
| 粒子数 | 30 |
| 最大迭代 | 100 |
| 独立随机种子 | 20 |
| 惯性权重 | 0.9 线性下降至 0.4 |
| 学习因子 | `c1=c2=2.0` |
| 训练场景 | 不少于 24 个 |
| 最终仿真测试场景 | 不少于 100 个未见配对场景 |
| 早停 | 连续 20 代改善小于 `1e-4` |

### 5.6 PSO 目标函数

建议采用：

```text
J = 0.45 × NEC_IAE
  + 0.20 × NEC_overshoot
  + 0.15 × pH_band_violation
  + 0.10 × control_total_variation
  + 0.10 × saturation
  + P
```

其中：

- `NEC_IAE`：归一化 EC 绝对误差积分。
- `NEC_overshoot`：归一化 EC 超调。
- `pH_band_violation`：pH 超出 5.8-6.5 的带外积分。
- `control_total_variation`：泵命令总变差。
- `saturation`：泵饱和时间或次数。
- `P`：硬约束惩罚。

以下情况直接判定为不可行解：

- pH <5.5。
- 无水时加肥或加酸。
- 泵命令为负且未被安全投影。
- 泵持续超限。
- 传感器/驱动故障下仍保持执行命令。
- PLC 许可条件失效后输出未归零。

### 5.7 参数选择和冻结

1. 使用 20 个独立 PSO 种子。
2. 每个候选解在全部训练场景上评价。
3. 先排除所有不可行解。
4. 在可行解中选择训练场景平均 `J` 最低的参数。
5. 保存收敛曲线、种子、参数、约束审计和哈希。
6. 在最终仿真和试验台验证前冻结。
7. 看到最终试验台结果后不得继续整定同一版本。

## 7. 各试验的执行方案

### E0 传感器与执行器标定

#### 目的

保证 EC 精度结论高于传感器噪声，并获得泵命令到实际流量的转换关系。

#### 步骤

1. EC 使用至少两个标准点校准并检查温度补偿。
2. pH 使用至少两个标准缓冲液校准。
3. 主水泵、NPK 混合母液泵和酸泵采用称重法或量筒法标定。
4. 每台泵低、中、高工作点各重复 3 次。
5. 记录启动延迟、死区、迟滞、稳定时间和最大安全流量。
6. 用参考压力表和流量装置校核压力、总流量。
7. 建立断线、漂移和超量程阈值。

#### 通过门槛

- EC 综合不确定度建议 ≤0.02 dS/m。
- pH 综合不确定度建议 ≤0.05。
- 泵实际流量重复 CV 建议 ≤5%。
- 如果 EC 不确定度不能支持 0.03 dS/m 判别，则不能声称达到 0.03 dS/m 控制精度。

### E1 三工作点 MIMO 对象辨识

#### 目的

获得真实试验台在低、中、高工作点的 2×2 动态模型。

#### 输出

- `K_EC_F`、`K_EC_A`、`K_pH_F`、`K_pH_A`。
- 每个通道的 `L` 和 `T`。
- 稳态 G 矩阵、行列式和条件数。
- 辨识拟合指标和独立验证指标。
- 重复间增益、延迟和时间常数的 CV。

### E2 约束解耦筛选

#### 条件

- 使用冻结的辨识模型。
- 候选 β：0、0.1、0.25 和 PSO 候选。
- 执行 EC-only、pH 扰动和联合扰动。
- 阶跃前最后 120 s 作为交叉响应基线。

#### 通过规则

必须同时满足第 4.3 节全部条件。不能只因为交叉耦合下降就认定通过。

### E3 固定 PI 与解析 IMC 对照

所有控制器必须使用相同：

- PLC 采样周期。
- 泵流量上下限。
- 变化率限制。
- 抗积分饱和。
- pH 低限逻辑。
- 无水禁加药。
- 通信和故障联锁。

只允许改变解耦开关和控制参数，不允许给拟议方法额外的安全或前馈优势。

### E4 PSO 离线整定

必须保存：

- `pso_runs.csv`。
- `convergence.csv`。
- 每个种子的最优参数。
- 每个不可行解的原因统计。
- `locked_controller.yaml`。
- 配置、模型和代码哈希。

20 次运行中建议至少 90% 获得可行解。如果最优参数总是贴在边界，需先检查问题定义和边界合理性，不能直接进入试验台。

### E5 仿真消融与鲁棒性

#### 仿真控制器

中工作点运行完整 C0-C5。

低、高工作点至少运行：

- C0：固定 PI、无解耦。
- C3：解析 IMC、带解耦。
- C5：PSO 离线优化 IMC、带解耦。

#### 仿真扰动

| 场景 | 扰动 |
|---|---|
| S0 | 标称模型 |
| S1 | 主水流 `q_w` -10%、+10% |
| S2 | 营养母液有效浓度 -10%、+10% |
| S3 | 酸液有效浓度 -10%、+10% |
| S4 | 各通道延迟 `L` ±20% |
| S5 | 时间常数 `T` ±20% |
| S6 | 按 E0 标定残差注入测量噪声 |
| S7 | 水流、浓度、延迟和噪声联合抽样 |

#### 最终测试

- 至少 100 个未见 `scenario_id`。
- C0-C5 在同一 `scenario_id` 下共享完全相同的扰动和噪声流。
- 以 `scenario_id` 为配对统计单位。
- 最终场景不用于重新选择 PSO 权重或参数。

### E6 物理试验台闭环验证

#### 试验结构

中工作点进行完整 C0-C5 对照：

```text
4 类工况 × 6 个控制器 × 3 次重复 = 72 次
```

低、高工作点比较 C0 和 C5：

```text
4 类工况 × 2 个控制器 × 2 个工作点 × 3 次重复 = 48 次
```

计划闭环试验合计：

```text
72 + 48 = 120 次
```

辨识和标定试验不包括在这 120 次内。

#### 四类工况

1. EC 目标阶跃。
2. 主水流 ±10% 扰动。
3. 母液有效浓度偏差。
4. EC 目标变化与水流/浓度联合扰动。

pH 试验以高于 6.5 的初始状态或自然扰动为起点，评价进入并保持 5.8-6.5 区间的能力，不要求酸泵实现主动升 pH。

#### 执行规则

1. 使用独立母液批次并记录实测浓度和温度。
2. 每次运行前恢复统一的水量、EC、pH 和温度窗口。
3. 在试验日或母液批次内随机控制器顺序。
4. 指标计算时使用匿名 `controller_code`，完成统计后解盲。
5. 所有控制参数在 E6 开始前冻结。
6. 每次试验之间执行规定的清水冲洗和恢复。
7. 保存失败运行；只有预注册的硬件故障或配液错误可以排除。

### E7 统计和复现

必须形成：

- 全部原始时序。
- 指标源 CSV。
- 控制器匿名和解盲表。
- 统计分析脚本。
- 所有论文图表的源数据。
- 代码、配置、模型和数据哈希。
- 失败运行和方案偏离记录。
- 从干净环境复现主要结果的说明。

## 8. 评价指标与验收门槛

### 8.1 EC 主要指标

| 指标 | 用途 | 建议门槛 |
|---|---|---:|
| 全过程 MAE | 总体精度 | 全部工况 ≤0.05 dS/m |
| 稳态 MAE | 精确跟踪 | 中工作点 ≤0.03 dS/m |
| EC 带内率 | 实际可用性 | 目标 ±0.05 dS/m 内 ≥95% |
| IAE | 过渡过程总误差 | C5 显著低于 C0，且低于或非劣于 C3 |
| 超调 | 防止浓度过高 | ≤10% 或按农业安全上限设更严格门槛 |
| 调节时间 | 动态速度 | 相对基线下降，绝对稳定带预先固定 |

### 8.2 pH 主要指标

| 指标 | 建议门槛 |
|---|---:|
| pH 5.8-6.5 带内率 | ≥95% |
| 最低 pH | ≥5.5 |
| pH 带外积分 | 相对 C0 下降或非劣 |
| 低 pH 时酸泵 | 必须停止 |
| pH 传感器故障时酸泵 | 必须停止 |

### 8.3 解耦指标

- 非目标输出峰值。
- 非目标输出 IAE。
- 平均交叉耦合降低率。
- 主回路 IAE 退化率。
- 解耦导致的负命令投影次数。
- 解耦导致的泵饱和时间。

### 8.4 执行与安全指标

- 泵命令总变差。
- 上限和下限饱和率。
- 抗积分饱和触发时间。
- 无水禁加药响应。
- 急停、驱动故障、传感器故障和通信超时响应。
- 通信恢复后是否出现自动重启。

### 8.5 稳态窗口

稳态窗口不能事后选择。

建议定义：

1. EC 首次进入目标 ±0.05 dS/m。
2. 连续保持规定时间后认为进入稳定状态。
3. 使用试验最后 120 s 计算稳态 MAE。
4. 如果始终未进入稳定带，则整段试验计入，并判定调节失败。

## 9. 随机化和统计分析

### 9.1 分析单位

- 仿真：完整 `scenario_id`。
- 试验台：一次完整 `run_id`。
- 时间采样点不是独立重复，不能把几千个采样点当作几千个样本。

### 9.2 随机化

- 以试验日或母液批次为区组。
- 在区组内随机控制器顺序。
- 工作点和扰动顺序应平衡化。
- 避免 C5 总是在新母液、低温或传感器刚校准后运行。

### 9.3 统计模型

仿真结果：

- 对每个 `scenario_id` 计算 C5-C0、C5-C3、C5-C4 的配对差值。
- 报告均值、中位数、95% bootstrap CI、标准化效应量和胜率。
- 多重主要对比采用 Holm 校正。

试验台结果：

- `date/batch` 作为随机效应。
- `controller`、`decoupling`、`tuning`、`working_point`、`disturbance` 作为固定效应。
- 中工作点分析解耦主效应、整定主效应及交互。
- 低、高工作点重点分析 C5 相对 C0 的泛化。
- 如果残差明显不满足正态性，使用稳健模型或预注册的非参数配对检验。

### 9.4 失败与排除

允许排除：

- 传感器明确断线或校准失效。
- 试验台泄漏、断电或管路脱落。
- 配液批次配制错误且有原始记录。
- PLC 程序版本与登记版本不一致。

不允许排除：

- 控制器性能差。
- EC 未进入目标带。
- pH 越界。
- 泵饱和。
- 结果不支持假设。

这些属于真实失败结果，必须保留并报告。

## 10. PLC 与安全验收

### 10.1 实际执行许可

实际执行许可应至少满足：

```text
Actuator_Enable_Request
AND 物理调试钥匙
AND Physical_EStop_OK
AND Field_IO_Ready
AND NOT Sensor_Fault_Any
AND NOT Drive_Fault_Any
AND Water_Flow_OK
```

任意一项失效，实际 AO/DO 应立即归零。

### 10.2 必测故障

| 故障 | 期望行为 |
|---|---|
| 主水流丢失 | NPK 混合母液泵和酸泵全部停 |
| EC 传感器断线 | 撤销自动加肥并报警，不继续积分 |
| pH 传感器断线 | 酸泵停止并报警 |
| pH <5.5 | 酸泵立即停止，需要人工确认 |
| 上位机心跳超时 | 撤销远程命令，PLC 安全停机 |
| 驱动故障 | 相应泵停止并联锁其他危险动作 |
| 物理急停 | 硬件回路切断，PLC 读取反馈 |
| 通信恢复 | 不得自动重新启动泵 |

### 10.3 部署顺序

1. Python 纯仿真完成 C0-C5。
2. PSO 参数冻结。
3. PLCSIM 验证采样、限幅、抗饱和、延迟补偿和故障逻辑。
4. 真实 PLC 使用逻辑 I/O，不接实际泵。
5. 完成物理急停、调试钥匙和驱动反馈。
6. 清水点动和流量标定。
7. 单路低浓度营养液测试。
8. 单路低浓度酸液测试。
9. 全部安全验收通过后进入 E6。

## 13. 投稿方向

该论文已经不是典型的田间灌溉管理论文，而是控制与农业工程交叉论文。

优先匹配方向：

1. **International Journal of Dynamics and Control**：强调动态模型、解耦、内模控制、仿真和试验验证。
2. **Applied Engineering in Agriculture**：强调水肥装备、PLC、传感器和物理试验台。

5. **Biosystems Engineering**：要求更高，通常需要更强的试验、模型创新和农业工程意义。

如果仍投 **Irrigation Science**，需要增加真实灌溉配方、农业工作点和应用意义，且最好补充盆栽或田间结果。只有混配试验台时，控制或农业工程期刊更匹配。
